# 🍔 Zomato Clone

A modern Zomato-inspired food delivery website built using HTML, CSS, and JavaScript.

## ✨ Features

- 🍔 Zomato-inspired landing page
- 🔍 Interactive search functionality
- 📊 Investor Relations page
- 💼 Business performance cards
- 📧 Email subscription interaction
- ✨ CSS animations and hover effects
- 📱 Responsive design

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Git & GitHub
